# SEO Expert in Itahari, Nepal 🚀

A production-ready, semantically optimized personal business and consultancy website for a Senior SEO Expert and Technical Search Strategist based in Itahari, Sunsari, Koshi Province, Nepal.

Built with **React 19, TypeScript, Vite, Tailwind CSS**, featuring an award-winning creative portfolio aesthetic inspired by modern engineering portfolios (0–100% preloader, cursor spotlight cards, ambient particle motes, film noise, infinite tech marquee).

## ✨ Creative Engineering & Animations

- **0–100% Preloader:** Numeric counter with progress track fill and curtain slide-up reveal.
- **Atmospheric Noise Overlay:** SVG fractal noise texture for a cinematic film finish.
- **Ambient Floating Dust:** Keyframe-driven floating particle motes drifting across the dark canvas.
- **Mouse Spotlight Bento Cards:** Dynamic radial gradient spotlight tracking cursor `(x, y)` across the 7 commercial service cards.
- **Infinite Tech Marquee:** Seamless continuous ribbon showcasing Core Web Vitals, Schema.org JSON-LD, Google Maps, and Semantics.
- **Live Terminal Simulator:** Interactive CLI crawler demonstrating speed tests, entity graphs, and audit logs.
- **Video Audit Screencast:** 5-phase interactive recorded audit walkthrough.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/nishapoudel201/seo-expert-itahari.git

# Navigate to the project directory
cd seo-expert-itahari

# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
